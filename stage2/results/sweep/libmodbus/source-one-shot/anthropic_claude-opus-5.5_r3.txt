**Primary finding:** an out-of-bounds heap write in the `MODBUS_FC_WRITE_AND_READ_REGISTERS` (function 0x17) handler of `modbus_reply`. The address check tests `mapping_address < 0` twice and never tests `mapping_address_write < 0`, so a network client can make the server write before the start of `tab_registers`.
