**Most likely vulnerability:** a heap out-of-bounds write in `modbus_reply`, in the `MODBUS_FC_WRITE_AND_READ_REGISTERS` (function 0x17) handler. A copy-paste error means the write address is never checked for being negative, so a network client can make the server write below `tab_registers`.
