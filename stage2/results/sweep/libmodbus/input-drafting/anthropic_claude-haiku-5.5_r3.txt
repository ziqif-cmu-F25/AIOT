**The bug, at the level of the code:** the fn-0x17 handler checks `mapping_address < 0` twice and never checks `mapping_address_write < 0`. Any check on the write-side address should cover the same bounds as the read side.

**Fix:**
```c
if (mapping_address < 0 || mapping_address_write < 0)
    /* return illegal data address exception */
```
Also verify that `mapping_address_write + nb_write <= nb_registers` (and the equivalent upper-bound check for the read range) before the write loop runs. Relying on a single upper-bound test that only covers one of the two ranges is what let the negative index through.
