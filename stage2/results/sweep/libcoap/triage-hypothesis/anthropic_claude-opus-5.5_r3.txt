Line 538 copies `address->length` bytes into the static `addrstr[256]` without any length check. A host of 256 bytes or more overflows the static buffer. A host of exactly 256 bytes also removes the NUL terminator, so `getaddrinfo` reads past the end. The AF_UNIX branch checks its length, but the normal path does not.
